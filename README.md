# Support Onboarding — версия с новой иллюстрацией

Откройте `index.html` в браузере или загрузите все файлы в GitHub Pages.

Структура:
- index.html
- styles.css
- script.js
- assets/evolution-01.png ... evolution-04.png

Иллюстрации разделены на 4 отдельных файла, поэтому на сайте они не растягиваются и каждый этап можно затемнять/подсвечивать отдельно.
