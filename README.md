# Support Onboarding v6

Внутренний одностраничный портал обучения Support.

В этой версии добавлены практические кейсы по ручной проверке чеков KGS_MANUAL, алертам по UZS/KGS и просадкам Humo/Uzcard.

Запуск: откройте `index.html` или используйте `python3 -m http.server 8080`.

Примечание: внутренние названия инструментов и разделов (KGS_MANUAL, Friendly Traders, Switch Bank, Credentials и т. п.) сохранены в исходном виде, чтобы соответствовать рабочему интерфейсу.
