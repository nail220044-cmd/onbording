# Онбординг службы поддержки — визуальный MVP

Одностраничный прототип на HTML/CSS/JS по согласованной концепции.

## Запуск

Открой `index.html` напрямую в браузере.

Для локального запуска через простой сервер:

```bash
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`.

## Примечания

- Серверная часть и авторизация не подключены.
- Прогресс чек-листов хранится в `localStorage` текущего браузера/устройства.
- Поиск поддерживает Ctrl+K / Cmd+K.
- Персонаж меняется на разных уровнях прогресса.
- Это визуальный/UX MVP; демонстрационные инструкции нужно заменить на утверждённые внутренние процедуры компании.


## Обновлённый визуал
В герой-блок добавлена кинематографичная иллюстрация эволюции персонажа от новичка до мастера.
